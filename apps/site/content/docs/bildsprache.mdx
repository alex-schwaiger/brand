---
title: Bildsprache
description: Zwei Bildwelten, Personenfotos und Projektbilder.
---

Die Marke kennt zwei Bildwelten. Sie bleiben getrennt, und die Farbtemperatur zeigt, welche gerade spricht: Die Person ist kühl wie Ink, die Arbeit liegt auf warmem Sand.

## Personenfotos

| Merkmal | Regel |
| --- | --- |
| Licht | Weiches Studiolicht von der Seite, keine harten Schatten |
| Hintergrund | Einfarbig, kühles Blaugrau nah an Ink |
| Farbstimmung | Kühl und gedämpft, natürliche Hauttöne, keine Filter |
| Kleidung | Dunkel, nah an Ink, ohne sichtbare fremde Marken |
| Haltung | Offen und ruhig, Blick in die Kamera |
| Ausschnitt | Im Web und im Portfolio quer bis Kniehöhe. Im Lebenslauf hochformatig ab der Brust. |
| Platzierung | Randabfallend oder auf Canvas. Nie auf Sand. |

Auf einem Personenfoto steht das Signet in Weiß, und zwar nur in einem ruhigen, dunklen Bildbereich.

## Projektbilder

| Merkmal | Regel |
| --- | --- |
| Grund | Sand, als Fläche auf dem Raster |
| Einpassung | Das Bild liegt eingepasst auf Sand, mit Luft rundum. Es berührt den Rand der Sandfläche nicht. |
| Inhalt | Das echte Ergebnis: Screens, Drucksachen, Logos. Keine Stockfotos. |
| Mockups | Schlicht und frontal oder leicht von oben. Keine Hände, keine Kaffeetassen, keine Schreibtischszenen. |
| Schatten | Höchstens ein weicher Kontaktschatten, wenn eine Drucksache sonst schwebt |

Auf Sand steht kein Text. Titel und Beschreibung stehen neben oder unter der Sandfläche, auf Canvas.

## Technik

| Medium | Auflösung | Farbraum |
| --- | --- | --- |
| Print | 300 ppi in Endgröße | CMYK, PSO Coated v3 |
| Interaktives PDF | 150 ppi | sRGB |
| Web | doppelte Anzeigegröße, AVIF oder WebP | sRGB |

Jedes Bild im Web hat einen Alternativtext, der den Inhalt beschreibt, nicht die Gestaltung.

## Nicht in der Marke

- Schwarz-Weiß-Fotos
- Verläufe, Duotone oder Farbüberlagerungen in den Markenfarben
- Bilder mit abgerundeten Ecken
- Collagen und schräg gestellte Bilder
