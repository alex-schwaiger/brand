## Abstände

Basiseinheit ist 8px. Die Marke ist großzügig: viel vertikaler Raum gehört zur Ästhetik.

| Stufe | Wert |
| --- | --- |
| 2xs | 2px |
| xs | 4px |
| sm | 8px |
| md | 16px |
| lg | 24px |
| xl | 32px |
| 2xl | 48px |
| 3xl | 64px |
| 4xl | 96px |

## Radius

Scharfkantig ist der Standard. Der Radius `0` signalisiert Handwerk und Autorität und tauscht Wärme gegen Strenge.

| Element | Radius |
| --- | --- |
| Karten, Flächen, Kacheln | 0px |
| Umschalter, kleine Buttons | 2px |
| Primäre und sekundäre Buttons | 2px |
| Tags und Chips | 2px |
| alles andere | 0px |

Die Laufweiten-Tokens stehen auf der Seite [Typografie](/docs/typografie).
